# Archive（历史 Loop 归档）

本目录存放已超出 `history.md` 保留数量（最近 10 次）的历史 Maintenance Loop 记录。

## 归档规则

- 归档文件建议按 Loop 区间命名：`loop-001-015.md`、`loop-016-030.md`。
- 归档内容为完整的历史记录原文（Loop 编号、日期、问题、证据、原因、修改、验证、剩余风险）。
- 归档后，在 `.agent/history.md` 的"归档索引"补充一条跳转记录。
- **日常维护 Loop 不主动读取本目录**；仅当需要回溯历史根因时按需查阅。
